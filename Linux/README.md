# WhisperType - Linux Edition

GPU-accelerated voice transcription with CUDA support.

## Run

```bash
whispertype
# Or: vc
```

You can also open **WhisperType** from the desktop Applications menu.

## Usage
- **F8/F9** - Start/stop recording
- Transcribed text auto-pastes at cursor
- Works with GPU acceleration automatically

## Check Setup

```bash
./Linux/test_setup.sh
``` 
